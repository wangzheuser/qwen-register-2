# 滑块临界区缩短设计

## 目标

在保留 Windows OS 真实鼠标拖动和现有成功判定的前提下，提高并发注册吞吐量；不引入隔离桌面会话，也不允许多个 OS 鼠标拖动同时发生。

## 方案

- 自动滑块的截图、图片解析、ddddocr/AI 识别和重试准备在全局滑块锁外执行。
- 每次尝试只在“置顶聚焦、真实拖动、立即确认结果”期间持有全局滑块锁。
- 单次失败后释放锁，再在后台刷新和计算下一次尝试；人工模式继续锁住完整人工处理阶段。
- Playwright 多线程共享的 ddddocr 实例使用独立互斥锁保护，避免并发调用未声明为线程安全的模型对象。
- 并发生成的验证码证据文件加入进程信息和纳秒时间，避免覆盖。

## 正确性约束

- OS 拖动的最大并发数仍为 1。
- 任何拖动前仍必须重新获得 Windows 前台焦点并置顶目标窗口。
- 拖动后的页面成功确认仍在释放前台锁之前完成。
- 注册提交确认、邮箱激活、令牌提取和保存继续并发执行；账号及邮箱文件继续使用现有跨进程锁。

## 验证

1. 单元测试证明识别发生在滑块锁外、拖动发生在锁内、多个识别可重叠但拖动不可重叠。
2. 运行相关测试和完整测试套件。
3. 通过 `start.ps1` 分别运行 Camoufox 与 Playwright 的真实并发注册，记录成功率、总耗时和滑块锁持有时间。
